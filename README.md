# RuangTugas - Manajemen Tugas Mahasiswa

RuangTugas adalah aplikasi desktop untuk membantu mahasiswa mengelola tugas kuliah dan deadline.

## Teknologi
- Java
- Java Swing
- MySQL
- JDBC (MySQL Connector/J)
- NetBeans IDE

## Fitur
- Dashboard dan navigasi halaman
- Menambahkan tugas
- Menampilkan daftar tugas
- Menghapus tugas
- Memilih deadline melalui dropdown tanggal, bulan, dan tahun
- Menyimpan data tugas ke database MySQL

## Instalasi
1. Instal JDK dan NetBeans.
2. Jalankan MySQL melalui XAMPP.
3. Buat database `ruangtugas` dan tabel `tugas`.
4. Tambahkan MySQL Connector/J ke Libraries project.
5. Sesuaikan konfigurasi koneksi database di `Koneksi.java`.
6. Buka project di NetBeans dan jalankan aplikasi.

## Catatan
Data tugas disimpan di database MySQL. Database perlu disiapkan secara lokal sebelum aplikasi dijalankan.
